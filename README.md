# EWOrganizer

A simple web app for organizing East West University semester schedules.

## 🌐 Live Website

[EWOrganizer](https://muhammad-mahirr.github.io/ew-organizer/)

## Features

- Upload semester schedule files
- Automatically organize classes by day
- View today's classes
- See upcoming classes
- Add, edit, and delete classes manually
- Automatically extract the student's first name
- Clean and responsive interface

## Built with

- React
- TypeScript
- Vite
- PDF.js
- SheetJS
